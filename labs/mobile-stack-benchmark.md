# Mobile stack benchmark

**In progress**

The apps share a catalogue of fictional hiking products. Each version lets you search, save favourites and open a product from the list.

<p><img src="../assets/labs/mobile-stack-benchmark/catalogue-6c5e0d63a8a0.png" alt="SwiftUI catalogue used in the mobile lab, showing fictional hiking equipment." width="180"></p>

## The experiment

I am comparing an instant transition with an animated one across Flutter, React Native, Jetpack Compose and SwiftUI. The work examines the rendered screens, the amount of code and build sizes within each platform.

The first phase uses Android emulators and iOS simulators. It does not establish a performance ranking on physical phones. The repository holds the applications and the protocol as the work progresses.

## Stack

`Flutter` `React Native` `Kotlin / Compose` `Swift / SwiftUI`
